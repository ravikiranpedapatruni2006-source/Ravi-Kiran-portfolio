# Ravi Kiran — Developer Portfolio

Dark, responsive React portfolio for Ravi Kiran, B.Tech CSE — AI & DS, Vel Tech University, Chennai.

## Highlights
- Hero: **LEARNING TO BUILD. BUILDING TO GROW.**
- Original uploaded professional photo used unchanged as `public/hero.jpeg`
- About, Skills, Projects, Certifications & Experience, Education and Contact
- ProConnect and Integrated Solid Waste Segregation System
- Deloitte Data Analytics Job Simulation
- Deloitte Technology Job Simulation
- 24-Hour Hackathon at Vel Tech University
- CCNA coursework
- GitHub, LinkedIn and email links
- GSAP animations and Lenis smooth scrolling
- Responsive desktop/tablet/mobile layout

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL (normally `http://localhost:5173`).

## Build
```bash
npm run build
npm run preview
```
